# GoLangAssignments  

This folder contains all assignments related to Go programming.  

### How to Run the Assignments  

1. **Navigate to the Assignment Folder:**  
   - Each assignment is stored in a folder named with the date it was given (e.g., `24-02-2025`).  
   - To move into the assignment folder, use:  
     ```sh
     cd GoLangAssignments/24-02-2025
     ```
     *(Replace `24-02-2025` with the folder name of the assignment you want to check.)*  

2. **Run the Main File:**  
   - Open the terminal and go to the folder of the assignment you want to check.  
   - Run the following command:  
     ```sh
     go run main.go
     ```
   - This will execute the assignment and show the output.  

3. **Check the Code:**  
   - Inside each assignment folder, you will find files named `Question1.go`, `Question2.go`, etc.  
   - These files contain the actual code for each question.  

This structure ensures that you only need to run `main.go` to see the output, while all the code is organized by question inside the assignment folder.
